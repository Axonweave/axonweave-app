# P4-5 - Study library, versioning, regeneration, preferences and export (Phase 4 M5, backend only)

## What was built
- **Library API** (`/study/materials`): list with search (title and stored payload, LIKE wildcards escaped), filters (type, workspace, subject, chapter, status, archived), allow-listed sorts, pagination (limit max 100); `DELETE`, `POST duplicate`, `archive`, `unarchive`. List items carry no content.
- **Versioning / regeneration**: already present from M1 (D-92: edit, restore, preview, apply, stale refusal); now covered by M5 tests (restore numbering, original kept, regenerate preview never overwrites a later edit).
- **Preferences**: `GET/PUT /study/preferences`; used as generation defaults only where the generator has the setting, the value validates and the request did not set it.
- **Export**: migration `0008_study_exports`; `POST /study/materials/{id}/export`, `GET /study/exports/{id}`, `GET /study/exports/{id}/download`. Celery task renders in the worker (PDF, CSV, Markdown, DOCX), stores in private storage, download is ownership-checked, short-lived (1 h), fixed filename, `nosniff`, `no-store`. Sweeper task resends undelivered exports and deletes expired files. CSV formula neutralisation; PDF drawn from plain text; Markdown escapes HTML/links; quiz and bank exports never contain keys. 30 exports/user/hour.
- **Account**: data export includes study materials, versions, cards, quiz attempt summaries (no keys) and preferences; deletion cascades and queues export files (also on material and workspace delete). Deleting a source document keeps materials and reports `unavailable_document_ids` / `unavailable_source_count`.

## Decisions made (with reasons)
D-100 in `docs/DECISIONS.md`; one-line choices in `docs/AUTOPILOT_LOG.md`. Notable: favourites not built (not in M5 list); quiz/question-bank duplicate is 422 (would copy answer keys); exports never include answer keys, even after submission.
