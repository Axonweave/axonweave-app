# P4-7 - Frontend for quizzes, results, exports and preferences (Phase 4 M7)

## What was built
- **Quiz page** `/study/{id}` (facts, attempt history, start, resume or retake), **taking** `/study/{id}/quiz`: question navigation, single and multiple choice, true/false, text answers, flag for review, progress, server-driven countdown, debounced autosave with a visible save state, submit confirmation listing unanswered questions, auto-submit at zero. A refresh resumes the open attempt with its saved answers.
- **Results** `/study/{id}/quiz/results/{attempt}`: score (or "Self-assessed"), counts, time taken, per-question review with the correct or model answer, rubric points and explanations (only after submission, from the results route), "not a measure of your overall mastery" note, auto-submit note, retake.
- **Question bank**: "Practise as a quiz" link.
- **Export**: format menu per resource type (matches the backend), progress, download link (about an hour), error messages per code.
- **Preferences**: Settings, new "Study material" tab (language, level, summary length, difficulty, include examples, definitions and references).
- Existing settings test updated from 5 to 6 tabs (deliberate UI change).

## Decisions made (with reasons)
D-101; AUTOPILOT_LOG rows P4-7. The client submits at zero but the server stays authoritative (it finalises expired attempts itself).

## Verified (exact command -> result)
- Vitest: 250 tests passed, including resume of saved answers, autosave payload, flags, unanswered warning, auto-submit at the deadline, redirect when the server says the attempt ended.
- Bug found by those tests and fixed: autosave used render-captured state and sent empty answers; the page now saves from refs holding the latest values.
- Playwright (`e2e/study.spec.ts`, 14 passed): full quiz with refresh-resume; **every network response under `/api/v1/study/` received before submit was checked and none contains `correct_answers`, `rubric` or the seeded explanation text**; results show explanations and 100 percent; a 4-second timed quiz is submitted by the page when the server deadline passes and the results say so; CSV export of a deck through the real worker, downloaded with `attachment` and `nosniff`; preferences saved and persisted after reload; a second user gets 404 for materials and quizzes; mobile layout has no horizontal overflow.

## NOT verified / limitations
- Quizzes are seeded (`backend/scripts/seed_study_e2e.py`, development and testing only) because the fake provider cannot write study JSON; quiz generation itself is covered by the backend tests.
- PDF and DOCX downloads were not opened in a viewer.
- The timer was tested with a 4-second limit; the minimum a user can set is 1 minute.

## HUMAN-NEEDED

- Open an exported PDF, DOCX and CSV (in Excel or LibreOffice) and check layout and that no cell is executed as a formula.
