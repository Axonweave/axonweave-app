# P4-3 - Phase 4 M3: Quiz generator and attempt engine

## What was built
Backend only.
- **Tables** (migration `0007`, one head): `quizzes`, `quiz_questions` (the only place the answer key, explanation and rubric are stored), `quiz_attempts`, `quiz_attempt_answers`. Composite owner foreign keys, a partial unique index allowing one open attempt per quiz and user, explicit grants.
- **Generator** `quiz` on the M0 engine, prompt `study_quiz` v1. Six types (multiple choice, multiple select, true/false, fill-in-the-blank, short answer, descriptive), difficulty, count (1 to 50), time limit, randomised order, language. Per-type answer-key validation (for example exactly one correct option for multiple choice), duplicate and answer-leak checks, source reference per question; unsupported questions are dropped; invalid output gets the engine's one correction call.
- **Endpoints** (`/api/v1/study/quizzes`): `GET /{id}` (no key), `POST /{id}/attempts` (start or resume), `GET /{id}/attempts` (history), `GET /{id}/attempts/{attempt}`, `PUT .../answers` (autosave and flags), `POST .../submit` (idempotent), `GET /{id}/results/{attempt}`.
- **Answer-key rule**: the material content stores only title and counts, pre-submission schemas have no key fields, and results are 409 until the attempt is submitted.
- **Attempts**: server-side deadline and lazy auto-submit, server-side grading (exact match for multiple select), per-question results persisted, retakes.
- Decisions D-94 to D-96, `AUTOPILOT_LOG.md` entries, M3 ticked in `TASKS_Phase4.md`. `tests/study/test_generation_flow.py` updated to expect `quiz` in the production generator list (same kind of update as P4-1 and P4-2).

## Decisions made (with reasons)
See D-94 (answer key), D-95 (retakes and timer), D-96 (scoring and subjective questions). In short: unlimited retakes with one open attempt; a 10-second grace for a submit's own answers; "show explanations immediately" is not offered because it would reveal keys before submission; short-answer and descriptive questions are self-assessed (model answer and rubric after submit), not graded, and excluded from the percentage.
