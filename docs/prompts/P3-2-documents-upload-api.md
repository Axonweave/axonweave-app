# P3-2 - Phase 3 M2: Upload and document management API
Follow docs/AUTOPILOT.md. Read CLAUDE.md, docs/DECISIONS.md, docs/TASKS_Phase3.md, docs/DOCUMENT_ARCHITECTURE.md and docs/PHASE3_SPEC.md sections 4, 5, 6.3, 19.1, 19.2, 21 and 22.5. Backend only.

1. POST /api/v1/documents/upload (multipart, multiple files): auth and CSRF; ownership of the target workspace/subject/folder/chapter verified through a reusable ScopeResolver that checks the whole parent chain belongs to the user (later reused by retrieval and Phase 4); size enforced while streaming; magic-byte validation for pdf, pptx, docx, txt, md, png, jpg, jpeg; filename sanitising; zip-bomb and image-bomb checks; per-user quotas; checksum; optional Scanner interface (ClamAV adapter, off by default); store in object storage; create document + version 1 + a queued job; enqueue the Celery task (for now it only sets a status); return ids and status.
2. Document APIs: list (pagination, search by name, filters by workspace/subject/folder/chapter/type/status, allowlisted sort), get metadata, PATCH (rename, move), status, processing details, retry, reprocess, secure download (streamed, nosniff, attachment), inline endpoint for PDFs with a sandbox CSP, delete.
3. Delete lifecycle exactly as in DECISIONS.md: DB cascade, outbox rows for storage objects, citations invalidated with the snippet cleared, nothing searchable afterwards. Account deletion removes all documents and objects; export includes document metadata. Tests prove this.
4. Replace-file flow: a new version while the old stays active until the new one completes. Build and test the version-switch transaction with a fake completion.
5. Security tests: spec 22.5 cases 1, 7, 8 and 10, plus path-traversal filenames, extension/real-type mismatch, oversize while streaming, quota exceeded, cross-user download/delete/retry/reprocess all returning 404, the unauthenticated sweep covering every new route, and no document content or storage keys in logs or responses.
6. Regenerate the OpenAPI schema and the frontend types.
